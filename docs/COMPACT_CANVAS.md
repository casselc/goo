# Compact facets and investigation context

An active population keeps its scope and next actions close to the data. Facets
use a compact shared header, loaded-value search and value rows; they keep the
qualified field, applied scope, full captured-record denominator and unknown
upstream coverage visible. Their models and explicit read/selection events are
unchanged.

**Loaded facet matches** announces how many supplied values match local Find.
`1 of 2 loaded values` describes the visible value list, not one record out of
the full population. Find, disclosure and display changes do not query telemetry.
**Read details** exposes the independent count/group receipts. Loading, error and
unavailable states remain distinct, and unrepresentable values retain their counts
without acquiring a selectable predicate.

The active scope shows its environment and fixed UTC window, including
milliseconds and the excluded upper bound. A same-day window prints the date once;
the tooltip retains both full ISO timestamps. Applied selectors appear once in
the existing scope disclosure, with a visible filtered marker. Critical staged,
pending, error and read-quality status stays visible.

A nested canvas names its current purpose. **Back to parent population** retains
its existing owner; **Parent paused** reveals the original parent/read explanation
without reopening or resuming it. Origin returns keep their named Back action and
literal resource title, while **Origin scope** exposes that origin's environment
and exact window. Origin facts are not a claim that a later child has the same
question. Trail history, Activity return and parent return remain distinct.

All these changes are presentation. They preserve selected values, held data,
source bases, query/record-page ownership and the existing explicit read boundaries.
Fine-pointer facet actions and inputs have 32px targets; coarse-pointer targets
are 44px. Native disclosures retain their keyboard behavior. Same-owner facet
updates retain Find and read-disclosure state; returning through a replaced facet
owner retains its values/receipts and may close the disclosure.
