# Product roadmap — 2026-11-05

This roadmap replaces the active execution order in the
[November 3 roadmap](ROADMAP_2026_11_03.md). Prior plans and reviews remain research
and historical validation, not parallel queues. The checkpoint is grounded in
[architecture](reviews/WHOLE_PRODUCT_ARCHITECTURE_332.md),
[design](reviews/WHOLE_PRODUCT_DESIGN_332.md), actual source and recent native work.
Proposed items below are not delivered capabilities.

The core remains **see what is happening → isolate a population → follow its
supporting signals → preserve or reuse the result**. Ordinary OTel data, one Go
executor, passive framework-neutral components and the checked view grammar are
the foundation. Held occurrences, fresh query results and immutable receipts
retain distinct authority and clocks.

## Deferred boundaries

Retain the existing distinctions for typed current/effective environments,
missing/empty namespaces, native metric temporality and uncertain coverage.
Comparison scope does not imply causality, and a source reread does not update an
immutable receipt. Broader facet/comparison modes beyond 337–338, more renderer kinds,
whole-view WYSIWYG, retention/restore promises and alert notifications need their
own demonstrated task and operational contract.

The facet 1,000-value cap is not a byte/DOM-work budget. Only a measured legitimate
case should select that conditional follow-up; exact values and focus must survive
without silent truncation. No DataFusion/XTDB/runtime replacement or broad
Datadog-parity catalogue is selected by this checkpoint.

## Lessons carried into 338

A count pair and a facet must preserve both original predicates and policies;
common intent is a checked delta, not permission to replace either scope. Reuse
the extracted categorical AST builder and the same explicit staging/Run boundary.
Pending choices must also guard generic Run and retained handlers, so a nearby
control cannot silently discard the user's intent.

For category comparison, independently acquire both original full scopes and
retain each read's clock and coverage. A category absent from a capped or uncertain
result cannot be presented as an exact zero. Missing keys and present-empty
strings need separate stable identities. Verify baseline-only values, asymmetric
predicates, independently failed reads and stale-response retirement before
promoting the display as a reusable grammar kind.

Use natural viewport frames to assess comparability and density. Actor DOM/API
completion and screenshot capture are separate claims: the 337 driver captured
repeated loading images despite completed DOM transitions. Keep independent
Playwright frames until that capture path is understood.
