# Passive chart frame

`goo-chart-frame` provides consistent chart headings, supplied units, window
labels, result state and a concise note. It is light DOM and framework neutral.
Load `chart-frame.mjs` and `chart-frame.css`; application code supplies the chart,
legend, explanation and native actions as ordinary child elements.

```html
<goo-chart-frame heading="Matching spans" unit="source records"
  window-label="Rolling [12:00, 12:05) UTC" state="stale"
  note="Last completed source read 12:05:02 UTC" heading-level="3">
  <goo-time-bars data='{"ceiling":"10","points":[]}'></goo-time-bars>
  <button type="button">Refresh current window</button>
</goo-chart-frame>
```

For an SPA, set `.data = {title, unit, window, state, note, headingLevel}` before
or after registration/attachment. The attributes are the canonical state;
`.data` returns a new plain snapshot. Set individual attributes to patch chrome.
Supported states are `observed`, `no_data`, `unknown`, `loading`, `partial`,
`stale`, `unavailable` and `incompatible`. Unsupported states display as unknown.
Text is rendered literally, bounded to 4096 characters per chrome field.

The element supplies `role="figure"` and an accessible label unless authored by
the caller. Heading levels 2–6 are supported, defaulting to 3. A metadata update
does not replace, move, query, hide or disable caller children; focused actions
and chart selections survive updates. Reattachment retains one chrome header.
It does not announce every update; the application owns explicit live status.

The frame does not infer freshness, completeness, health, numeric compatibility,
axes, a rolling window, rates or percentiles. It never reads telemetry, starts a
timer, subscribes, navigates or freezes evidence. The application must disclose
the exact window and source clock and decide whether stale plots remain visible.
Chart primitives retain responsibility for their own exact labels and geometry.

`tests/chart-frame.test.js` covers the pure metadata model.
`journeys/chart-frame-components.spec.js` exercises server HTML, pre-upgrade SPA
properties, focused native children, repeated metadata patches, safe text, mobile
containment and zero source reads with synthetic standalone component fixtures.
These fixtures validate display contracts, not live telemetry integration.

on 2026-10-20. The desktop and mobile frames were generated by the tests:
