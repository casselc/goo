# Investigation controls polish

This pass applies the shared workbench hierarchy to the surfaces added since
service-version comparisons: exception groups, captured rates, recorded Error
comparisons, contextual actions and counted facets. It precedes the next
functional roadmap item, contextual field-constraint editing (424).

The main improvement is progressive disclosure: values and choices come first;
exact scope, independent read receipts and calculation facts remain inspectable.
Observed fields and counted facets use responsive searches. Observed suggestions
keep their incomplete status visible, with exact buffer provenance in Observation
details. Counted facets use a single responsive selection toolbar. Search and
selection remain local, counts still describe the original loaded population,
and Stage remains an explicit atomic draft change. Missing, empty and literal
values retain distinct native checkbox labels.

Shared comparison values expose contextual Calculation controls rather than
repeated state names. Visible support retains numerator/denominator, count and
exposure, unknown coverage and empty-side distinctions. Independent populations
remain independently measured; neither the presentation nor a disclosure changes
query or source ownership. Exception signatures remain available through native
contextual disclosures. Inspector and contextual action structures already match
the shared workbench and retain their existing focus behavior.
