# Inspect the span page that was captured

A saved span capture can show its current retained page as a Table or Span waterfall. Changing representation, adding a supplied field, inspecting an occurrence and returning stay within stored evidence. **Expand trace (fresh read)** remains a separate source operation.

The ordinary OTLP fixture contains three traces across multiple services. Scalar scope matches 1007 spans; effective typed scope matches 1014, including interleaved legacy-resource observations and excluding conflicting current environment labels and other namespaces. Both captures retain 1000 records and expose 100 records per inspection page. The local waterfall does not claim that its 100 rows are a complete trace or the full population.

Exact nanosecond strings include low digits beyond JavaScript's safe integer range. The current page contains two distinct observations with the same trace/span IDs, an ambiguous reported parent, a missing parent and a known zero duration. Invalid timing and maximum-integer boundaries belong to generated tests; this journey does not fabricate malformed successful source responses.

1. Capture genuine source data, then refuse the upstream source and prove a real query fails.
2. Reopen each immutable capture, switch to Waterfall and add the literal occurrence attribute as a display field. Verify query/focus/keyboard continuity and unchanged source receipts.
3. Inspect a duplicate-ID occurrence by its original page position and compare the complete inspector record with that exact stored row. Close details and change back to Table without reading telemetry.
4. Hold a genuine stored-page response, invoke the departed Inspect callback and verify no publication. Complete the page change, return to the first page and prove the old callback remains inert while the new one works.
5. Separately restore the source and explicitly expand the selected trace. Fresh spans and linked logs retain the original environment policy and fixed bounds while deliberately dropping the captured search's other predicates.
