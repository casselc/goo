# Activity log volume and exact interval explanation

Executable: [activity-log-context.spec.js](../../journeys/activity-log-context.spec.js).
Both real-source journeys pass, including the 30-second Bombadil campaign.
[Validation](../../VALIDATION.md) and the
[independent acceptance](../reviews/ACTIVITY_LOG_CONTEXT_REVIEW_413.md) record
actual results and limits.

The operator starts a manifest-free Activity view over ordinary OTLP logs. A
624-record matching bank is deliberately larger than the 100-record retained
browser buffer. Two OR branches admit different services; unrelated records and
a conflicting current/legacy environment control remain excluded. Exact empty,
ERROR, INFO and custom severity text coexist with conflicting numeric severities.

| Step | Natural interaction | Objective check |
| --- | --- | --- |
| Start | Start the saved Activity scope, then Pause. | No log-context aggregate request occurs implicitly. The retained buffer contains 100 occurrences, independently of the full population. |
| Show | Show volume for the last completed 60-second window. | Exactly one aggregate API request and three SQL statements. Raw ClickHouse rows independently establish complete count, exact severity-text groups and six 10-second bins. No inspection rows/fields are returned. |
| Refresh | Reread manually while paused. | Same fixed scope, one request/three SQL. A retired bar reattached into the fresh plot cannot dispatch a selection. |
| Select | Drag across two actual bars, then use Space/Shift+Arrow/Enter after Refresh. | Pointer and keyboard routes pause/hold without source reads. Shared time-bar interaction stays active; stale bar callbacks cannot acquire the new plot's authority. |
| Freeze pending refresh | Start a real held COUNT read, then drag two bars in the retained chart. | Interaction aborts the pending refresh without another aggregate attempt. Its late failure cannot replace the old chart/window; Explain/Close confirms the old selected UTC bounds. Cancellation metadata is not mislabeled as a new telemetry read. |
| Inspect severity | Open exact reported severity text counts. | Empty and custom strings remain distinct; ERROR text with INFO number is still an ERROR-text group, not inferred numeric severity. Disclosure/cadence choices are local. |
| Hold | Resume the stream so its completed window advances while the manual aggregate stays held. | The chart retains its original UTC bounds and read basis. Selecting its final 20 seconds explains that old window, not the newer stream window. |
| Explain | Explain interval, select cohort, then explicitly Run explanation. | Keyboard entry focuses the visible explanation heading and Close restores its trigger without reads. The paired requests preserve the exact original OR predicate/environment; selection and preceding equal-width baseline are independently checked against raw records. |
| Follow/Back | Stage a selected-side cohort question, explicitly Run, then Return to paused Activity. | Refined predicates preserve OR under AND. Return adds no reads and restores the held records, explanation and original aggregate window. |
| Refuse | Plant a real upstream failure, then hold a reread and change environment. | Failure produces no actionable chart; disabled/retired callbacks cannot overlap or restart reads, and late completion cannot adopt. |

A second bounded smoke test uses six real OTLP spans to load and refresh the
existing Activity latency panel. This checks the other consumer of the extracted
read gate with nonempty source data. Both tests bootstrap the inert fixed-question
app before creating fresh rolling-window fixtures, so asset startup time cannot
expire the sample before Start.

The optional 30-second Bombadil campaign gets a fresh ordinary bank and Activity
view. It exercises Start/Pause/Show/cadence/selection/explanation, requiring
completion, contained layout, no unexpected writes and no extra aggregate reads.
The real report at `artifacts/activity-log-context/report.json` retains successful
aggregate carriers, raw-row oracle, actual gesture counters and refusal evidence
for the independent Hegel/Quint validation gate. The isolated runtime and proxy
are stopped in `finally`, including failures.

The passing log journey measures 624 matching records against 100 retained
occurrences. Its 30-second actor completes the selection/explanation workflow
without implicit reads or writes. Documentation fixtures are generated after
app startup so a slow launch cannot expire their rolling window.
