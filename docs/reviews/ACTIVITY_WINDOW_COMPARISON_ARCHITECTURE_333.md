## Handoff and authority

Freeze the completed applied Activity window once at click admission. Preserve
logs/spans signal, exact typed environment selector (including policy), namespace
predicate and all filters. Derive the baseline as `[from-width,from)` from selected
`[from,to)`; do not consult a later wall clock. Page offset is zero. Reject invalid,
unsafe, inverted, non-completed or before-epoch windows rather than repairing them.
A changed scope, unapplied draft, inactive/departed owner or pending/reconnecting
window cannot authorize a retained click. Rechecking the actual owner at dispatch
is required even if the button was enabled earlier.

The handoff contains questions and display layout only. It contains no retained
rows, population count, source basis, capture receipt or result authority. Use the
existing checked `stagedView` handoff and Go view admission when staging a complete
composition. Stage and local Back add zero telemetry reads or writes; explicit
Run owns the selected and baseline acquisitions. Independent source read clocks
remain distinct from Activity's completed polling window and any receipt custody
clock. No staging timestamp is evidence of either source read.

Reuse Activity's existing local parent anchor and paused return. Return restores
the held rows and scope without a new Apply, resume, telemetry read or adoption
from a departed fixed request. Retired callbacks and ABA scope changes must fail
owner admission even if selector text later matches again.

## Passive role labels

Application adapters supply role labels to passive comparison presentation. Fresh
fixed adjacent queries use **Previous window** and **Selected window** throughout
Summary, Groups, accessible table headers, chart labels, titles and tooltips.
Same-window fixed comparisons use **Fixed baseline window** and **Selected
window**. **Frozen baseline** and **Current held** remain reserved for their
actual frozen/held owners; captured latency and other independent adapters retain
their own meanings. The display component must not infer ownership by fetching,
subscribing, reading app state or examining a count. Reuse EvidenceScope for
operand scope and read facts. Labels change presentation, never acquisition.
