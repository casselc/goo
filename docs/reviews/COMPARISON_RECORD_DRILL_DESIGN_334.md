## Interaction contract

Keep the existing inline native count buttons, natural operand column headers,
keyboard names, shared bars, Find and order. A child must visibly identify the
chosen role and typed category, retain the independent-read attribution and make
Back and explicit Run easy to find. Exact category values remain inspectable;
missing, empty string and literal text remain distinct. Render roles as literal
text using the existing checked role contract.

The planner copies the selected operand's exact fixed half-open UTC window,
signal, typed environment policy, namespace presence, existing predicate tree,
requested measures and delivery limit. It appends one admitted typed group
predicate and resets only offset. It must not derive identity from display labels
or substitute the current wall clock, other operand or inspection-page offset.
The narrowed child does not inherit the whole-population comparison reference.
A fresh Run may observe different records/counts because the held summary is not
record or snapshot authority. The supplied parent pair remains unchanged.

Selected records already have an explicit Clear selected records action in the
record selection tray. Keep refusal non-destructive. Add no duplicate clear
control unless an actual native pass demonstrates that the existing action is
unreachable or its required context is unclear. Likewise preserve existing dirty,
pending, depth and stale-action refusal; no convenience gesture should weaken
current-owner admission.

Return uses the existing Back to parent population action. It restores the same
held pair, local group Find/order/page, independent inspection page, scroll and
fresh opener focus without source IO. Previously retained action handles remain
retired; fresh controls may bind to the unchanged held evidence.
