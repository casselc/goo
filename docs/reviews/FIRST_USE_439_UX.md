# First-use acquisition and retained return: UX review

## Review scope

Independent review of the 439 raw-observation lifecycle consolidation. This is a
fixed, held read, not live monitoring, a readiness cache or a saved capture.

## Source review

The existing Read observations, Find, paging, attribute detail and shared table
components retain their roles. Temporary departure ends request authority while
retaining a previously settled bank, exact source-read receipt, fixed window,
local Find/page and selected detail in the same mounted owner. Returning does
not read values or move focus. An operator can inspect held rows without paying
for a new source read.

Pending-only departure clears the pending inspector. Departure during a reread
aborts and advances the request generation, retaining only the prior settled
bank with a concise cancellation status. A late successful response cannot
replace that bank or move focus after return. New discovery, source-scope edits
and explicit Close remain destructive retirement boundaries. No data is
silently carried into a different question.

Find now checks owner activity and native control eligibility like paging and
Inspect. Hidden retained controls cannot mutate the presented selection through
obsolete callbacks. Close still restores an eligible Read opener; passive
suspension does not restore focus or open disclosure ancestors.

The focused raw-observation test module passed during this source review.

Reviewed the genuine [1440 px](../journeys/screenshots/439-acquisition-1440.png),
[390 px](../journeys/screenshots/439-acquisition-390.png) and
[320 px](../journeys/screenshots/439-acquisition-320.png) frames. The desktop

Inspect/paging controls and distinct observation/source-read times. Long precise
read clocks wrap at 320 px without horizontal overflow. The cancellation status
is concise and preserves the distinction between stopped acquisition and held
observations. No new component or extra explanatory panel is needed.

The real browser journey activates Inspect using keyboard Enter and compares
the exact held bank before and after mode return: source receipt, fixed request,
visible keys, Find text, page and selected detail. The returned Metrics mode
control retains focus. An actual completed source response is held across a
pending navigation and later delivered; the prior held bank and focus remain
unchanged. Local operations and return do not trigger new source work.

UX source and responsive-frame acceptance: **accepted, no blocking findings**.
The parent validation record owns final browser/native gate results. This review
does not claim physical screen-reader or cross-engine testing.
