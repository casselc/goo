## Scope and template semantics

The HTTP population must keep its existing exact nonempty service selector,
reported Server kind, nonempty current `http.request.method` requirement, typed
environment and fixed bounds. No protocol/legacy attribute union, scope inference,
query projection stripping or additional acquisition executor is introduced.
The route remains the chart category; the facet binds the literal qualified field
`attribute:http.request.method`, with applied-scope counts and explicit Read values.

Allow otherwise valid ordinary category templates to contain a facet. The prior
blanket refusal was a first-cut bound, not a fundamental semantic conflict. Do not
replace it with an HTTP-specific magic field/profile exception. Existing template
expansion changes only its declared category grouping; the facet's qualified field,
title and basis remain literal and unchanged. Destination composition validation
checks signal/field/profile eligibility. Category rebinding must never rewrite the
facet to the destination category, import source predicates or transfer loaded
values. Existing facet+comparison and fixed-query-template prohibitions stay intact.

Remove the matching blanket Go/browser/schema/authoring-marker exclusions together.
Binding is retained/displayed only when the complete ordinary template is valid.
No new parameter system, registry or renderer kind is needed. The existing
source-free template expansion and normal Save/export/catalog remain owners.

## Existing profile behavior

Shipped HTTP expansion already admits some selected widget queries with numeric
measures, preserving their complete query and omitting the category-template marker
when unsupported. The new facet cannot be attached to such a specialized query.
Preserve that existing behavior: numeric HTTP customization retains its exact
query, prior two-role composition and omitted template marker. Add the new default
facet conditionally only to eligible ordinary HTTP populations; never remove
numeric/profile fields merely to make the facet validate.
