## Find a saved display without copying its ID

Inside the existing Native histogram view disclosure, add explicit Browse and
More metadata-page actions plus Find loaded views. Each page scans at most 20
lexicographically ordered IDs. Search covers only accumulated loaded pages; label
that scope directly. Lexicographic ID order is neither newest nor relevance order.
Do not imply a total catalogue count or complete search before all pages are read.

Use the existing accessible row action to Inspect title, Histogram/Table and exact
unit, with a compatibility hint for the current validated destination. Metadata
rows are leads, not authority. Inspect must GET/validate the actual artifact before
Apply becomes possible. Apply preserves the current whole question, clears prior
result and stages explicit Run; the user then selects an actual destination export
interval. Donor scope, result, clocks and selected interval never transfer.

Keep exact Native histogram view ID as an advanced escape hatch, visibly distinct
from Measurement package revision. A short human loaded title/kind/unit is primary;
raw loaded configuration belongs in existing closed details rather than opening a
JSON wall. No new registry, workspace, component framework or automatic reads.

## Partial discovery and current ownership

An invalid/unreadable artifact page needs a bounded diagnostic, not a fake empty
library. Say no usable views on this scanned page versus no views loaded; preserve
More when continuation exists. Loaded/matched/scanned counts are distinct. A
compatible summary cannot authorize Apply if its artifact later fails validation.
Wrong unit/kind remains a precise refusal without destination mutation.

Browse, More, Find and Inspect keep pending states/action leases bound to the
current validated question and visible disclosure. Changing destination, hiding or
replacing owner retires late metadata rows and old actions. Find should not discard
a verified selected view/draft merely because it is outside the current local
filter; identify that state through existing library patterns. Accessible action
names include the actual title/revision, and current focus survives list updates
without taking unrelated focus.
