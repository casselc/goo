## Why this order

and duration declarations already exist, while direct Customize rejects them.
Expose the existing useful path without another aggregate calculation or editor.
398 gives that breadth deeper temporal value through the existing grouped model,
but admits mean only when exact raw sum/count support is proved. 399 then removes
a demonstrated passive/application dependency cycle rather than inventing a
universal lifecycle abstraction. This is breadth → depth → consolidation, not a
native-only sequence or a list of every reviewer suggestion.
