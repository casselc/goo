## Why this cadence

397 exposed already-supported quantitative displays through direct customization;
398 deepened the same shared model with exact raw-span means. Repeating another
quantile or renderer expansion now would continue one facet while leaving an
existing presentation outside the grammar. Summary authoring is the next bounded
breadth improvement because source facts and passive rendering already exist.

401 then deepens native investigation through the operators' Services and Saved
entry points. Ordinary gauge nearby-record context is delivered, so this is
retained-evidence adoption, not new time math or an invented interval. Its risk is
custody/membership and capability renewal, addressed by explicit gates rather than
passing a generic callback through.

402 consolidates a human-visible problem in actual quantitative and grouped
frames: later columns/intervals can be hard to discover and compare while identity
moves away. It does not falsely classify keyboard focus or region semantics as
missing; `goo-table` already has both. This balances grammar breadth, investigative
depth and shared-component usability.

## Lessons and exclusions

- A correct leaf validator is not enough.398's enclosing view schema still assumed
  count-only grouping; future role/profile acceptance must exercise real carrier
  schemas, stores and consumer wrappers with negative controls.
- Exact support precedes plotting.398's sum/count gate justified means only.
  Grouped P95 and averaged scalar percentiles remain outside this sequence.
- Source acquisition, local presentation and retained-context staging are separate
  capabilities. Neither Back nor a valid local edit renews all of them.
- 399 is a structural dependency closure. It must preserve real displays and effects;
  no review measured a performance gain. Go1.27.3 is already current here, so there
  is no upgrade-only migration or clever caller-facing generic API to schedule.
- Existing Live Keep, typed filters, comparisons, trace waterfalls, service/resource
  views, captures, reviewed export, direct quantitative Customize and grouped mean
  reuse remain delivered. They are not reintroduced as missing core primitives.

The next whole-product review follows402, with earlier reassessment if source or
custody feasibility fails. Deferred candidates stay reconciled rather than silently
becoming parallel backlogs.
