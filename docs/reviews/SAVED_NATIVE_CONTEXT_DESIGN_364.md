## Natural existing gesture

Keep **Logs in interval** and **Spans in interval** inside the existing selected
counter/histogram interval inspector. The saved renderer supplies the existing
context callback, not a new panel or universal navigator. Choosing a link stages
an exact record question; only explicit Run reads records. Preserve the selected
native interval, stream and source observation even when whole-window coverage is
unknown. Unknown interval values do not fabricate a numeric contribution.

The child origin should say **From saved native interval**, with a short capture
citation and full immutable receipt in the existing Retained native origin
disclosure. Keep its frozen question/source-read/custody clocks independent of
new child evidence. Reuse the established exact nanosecond membership and resource
identity mapper; metric-only attributes never become record predicates. Shared
resource/time is context, not exemplars, contributing requests, causality or an
atomic cross-signal snapshot.

Use **Return to saved measurement** for this parent. Restore the held immutable
capture, selected interval and sensible current opener focus without rereading
native telemetry. A source-free metadata fetch, if the existing owner needs one,
must be counted separately and must not be described as a native reevaluation.
The existing live parent keeps its own return wording/ownership; do not force a
saved capture through a live measurement plan or change route acquisition modes.

## Refusal, cancellation and custody

A child source failure remains unavailable, not no-data/zero. Cancellation is not
a failed or empty measurement. The origin/return gesture remains available while
the child is staged, reading, refused, cancelled or inspected. Return cancels and
retires current child work; late responses and old hidden links cannot take focus,
publish results or stage another question. Unrelated current focus is not stolen.
No automatic retry or broadening follows failure.

Gauge/stock observations and aggregate histogram time buckets retain existing
context refusal; no invented lookaround interval. Missing/empty/named namespace
and exact service instance remain distinct. Further trace expansion keeps its
existing broader enclosing-window disclosure and independent fresh read budget.

Replace the existing tab-only origin disclaimer only for a verified saved parent:
the capture citation is durable, while a saved/shared child question alone still
does not retain the origin or create a joint snapshot. Original saved bytes and
receipt never change because a child was explored or captured.
