## Contract

An operator explicitly discovers reported resource `service.version` groups inside
one coherent span widget's qualified service, namespace, typed environment and
fixed window. Existing profile/operation predicates remain in the original AST.
Discovery uses one aggregate request with count/groups, not retained row counts.
Missing, present-empty, whitespace and literal version values remain separate.
Two values must be chosen explicitly. Selecting/staging does not read telemetry.

Count and mean span duration reuse the existing same-window query-comparison
carrier. Both queries restore the original grouping and retain their respective
version predicate. Span-status error fractions and grouped scalar percentiles are
not claimed by this count/mean carrier. Deployment attribution or causality is not
inferred from version differences.

## Source review

The pure projection refuses incoherent widget identity, wildcard namespace and
unsupported source/query shapes. Aggregate DTO admission checks conserved counts,
canonical integers, independent read receipts, exact query identity and distinct
groups; changed reads cannot produce actionable choices. Unsupported literal
predicates are visible but disabled rather than rewritten.

The application owner requires a current visible control and accepted widget
result. Discovery pending state participates in dashboard pending/canLeave gates.
Closing during a read cancels its generation; parent departure retires it. A late
response cannot restore choices or stage from a suspended/retired owner. Existing
service staging and held Back retain their own authority; passive display
components gain no fetch/navigation role.

The two version choices have visible labels as well as accessible names.
Personally inspected final desktop, 390px and 320px frames: compact native
controls remain contained, missing/empty counts stay visible, and focus is visible.
The existing shared comparison bars put 132 and 168 captured records on one scale
with an explicit 36-record difference. The discovery-specific Read details
disclosure exposes its own completion/count/group clocks and bases separately
from the earlier parent widget; keyboard Enter and open narrow containment pass.

## Verification scope

`verification/serviceversions` exercises actual JS projection against an
independent Go oracle, Go compiler and exploration-view validator. Generated
cases include typed environment policies, namespace identity, exact operation
predicates, literal missing/empty/Unicode/whitespace versions and counts beyond
JavaScript's safe integer range. Rejecting DTO/scope/value controls are included.

The Quint model checks explicit discovery, staging, Run and held-return gesture
budgets. Actual per-gesture report replay deliberately separates initial service
reads and a separate browser actor; the final pending request is modeled as
started and then retired. It is
not an assertion of a transactional source snapshot or exhaustive run completion.
Browser execution is responsible for real-source membership, completion and
retired callback checks. Actual commands and outcomes belong in
[validation](../../VALIDATION.md).
