## Decision at checkpoint (pre-correction source findings)

confirmed duplicate pending receipt GETs and late adoption after departure within
the same Saved workspace. This breaks the user’s current destination and outranks
the presentation seam below. Source reviewed here corroborates the risk: general
`open()` increments a generation but has no route-scoped abort/admission owner;
`sharedLink()` handles both hashchange and popstate and checks only an already
loaded current receipt. A pending same-ID visit is not deduplicated, and departure
to another hash need not invalidate it. This is source corroboration of root’s
finding, not this reviewer’s fresh native reproduction.

The bounded correction should give one navigation intent one verified receipt GET,
retire pending work on same-workspace departure before abort, reject late success
and failure publication, and permit an explicit retry. Preserve stored-page paging,
explicit refresh/new custody, and retained child return as distinct operations.
Opening saved evidence must never steal the destination or focus after departure.
Loaded same-ID reuse is a visit policy, not a universal cache or fresh-verification
claim. No new UI surface is needed.

Keep **comparison operand naming through the passive presentation** as the next
finite consolidation, rather than expanding the current correction.
The existing adapters already know what each side means, but the shared group
component discards that meaning. This is a demonstrable cross-task clarity defect,
not a reason to merge acquisition owners or extend the kept-action sequence.

In maintained `323-after-fixed-previous.png`, the facts say **Previous window** /
**Selected window**, with independent 5/9 counts and separate source-read clocks,
but the group table says **Baseline** / **CURRENT HELD**. The selected operand is
an acquired full fixed population, not Activity's loaded occurrences. This also
obscures the selected/rest and overlapping-parent distinction. The correction is
small enough to prove with the existing fixed and temporary comparison tasks.
