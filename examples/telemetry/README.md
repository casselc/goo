# Shared sample investigation packages

These six ordinary telemetry packages are the primary Examples UI experience.
Generate work in the reservation, Go checkout or Go reports sample, then open its
span/log package. Explore uses the normal Go adapter/compiler. Apply a recipe,
refine the population, Create package to save a variation, Capture investigation
to freeze evidence, and add the exact capture to ordered investigation notes.

A five-minute lookback is resolved when the package runs; captured evidence fixes
those bounds. The reservation selector includes web/gRPC/consumer records with
an OR, not an invented shared service identity. Scope must be narrowed explicitly
when a recipe should cover one span kind, instance or operation. Go samples may
have no log records; empty results remain no-data rather than inferred health.

The specialized lifecycle/resource lab and Go operation/native-metric manifests
retain separate contracts. These definitions do not replace deadline evaluation,
subject outcome reconciliation or reset-aware metric kernels.
