# Keep a useful quantitative distribution

397 extends the ordinary distribution continuation to already-supported numeric
and span-duration measures. This storyboard is executable in
[the actual-source journey](397-quantitative-customize.spec.js); execution results
belong in VALIDATION.md. Frames are generated by that journey, not mockups.

1. Run an ordinary log numeric question, span numeric question, or span-duration
   question. Its nested predicate, explicit environment policy, exact bounds and
   nondefault three-record page remain intact. The fixture reports signed, zero,
   missing, present-empty and invalid numeric input independently.
2. Select **Mean** in the existing breakdown measure picker and find `read`.
   **Customize** stages that exact measure and complete question. Staging shows no
   chart and reads no telemetry.
3. Explicitly **Run population view**. Inspect independently checked source totals
   and group aggregates, switch to **Table**, order by label, and find `write`.
   Local presentation changes read no telemetry and do not change the measure.
4. Save the reusable configuration. **Back to question** restores the held parent
   with its original Find, dataset revision and presentation, without a reread.
5. Inspect the saved display over a different compatible destination question.
   **Apply** stages it; only explicit **Run** acquires destination evidence. The
   destination environment policy, predicate, bounds and page limit survive.
6. On a narrow viewport the same chart/table controls remain usable. Hidden,
   inert, pending and superseded Customize callbacks cannot stage a population.
   Page-offset, empty and failed results cannot claim usable complete evidence.

A separate Bombadil campaign independently performs the numeric source →
Customize → explicit Run → Table → held Back flow, checking exact source request
identity and the selected numeric measure. It is not a pixel oracle.
