# Shared formatting without an application import

399 is a structural consolidation. The user flow and mathematical meaning stay
unchanged. This [actual-source journey](399-display-helpers.spec.js) exercises the
specialized grouped renderer that consumed the extracted helpers, complementing
the shared grouped-mean journey from 398.

1. Run an ordinary OTel span question over twelve physical spans. A qualified
   group, duration summary, reported span status and declared numeric binding
   retain one exact fixed question and a nondefault three-record page.
2. Inspect count, mean duration, p95, recorded Error percentage and four numeric
   measures over the complete grouped data. Raw persisted times, attributes,
   duration and status establish each cell's independent arithmetic and scale.
   Missing keys, present-empty and literal `雪` remain distinct; negative numeric
   labels keep their sign while bars use absolute magnitude.
3. Find `雪`, then clear Find. The full captured scale and hidden series' values
   remain unchanged. Metric selection and Find add no source reads.
4. Select an actual interval, inspect its staged fixed question and return to the
   held question. The selected mean, groups and widths stay local; staging and
   Back add no telemetry reads.
5. Read the same renderer at 390px. Current desktop and narrow frames are captured
   by the app, not mocked.
6. Run the same physical source grouped into duration buckets. Use a keyboard
   rectangle to select two time intervals and `[5,50) ms`. The passive component
   emits raw geometry; the application constructs the exact scope, preserving the
   complete parent predicate and inclusive nanosecond upper bound. Inspect stages
   that fixed question without evidence or a source read; Back restores the held heatmap.
