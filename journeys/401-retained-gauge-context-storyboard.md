# Follow a retained gauge observation

The executable [main journey](401-retained-gauge-context.spec.js) follows ordinary
OTel process gauge data from Services and immutable Saved evidence. The
[actor companion](401-retained-gauge-context-actor.spec.js) independently explores
an unavailable Saved observation. Execution results belong in VALIDATION.md.

1. Discover the service in its exact environment and named, missing or present-empty
   namespace. Open its dashboard and the existing retained native result. Select a
   reported gauge timestamp. A real zero and an unavailable value both retain the
   actual reported timestamp; neither creates an invented interval.
2. **Logs around observation** or **Spans around observation** previews the existing
   ±60-second scope, clipped to the original metric question. The source service,
   instance, namespace and environment policy stay exact. Metric attributes and
   unrelated resource labels are not copied into record predicates.
3. The fixed record question is staged without a source read. Explicit **Run**
   obtains fresh ordinary record evidence. Raw persisted records independently
   establish membership at each nanosecond boundary.
4. **Back to service** restores the same dashboard widget, stream, selected point
   and context with focus on the original action. It does not reread native metrics.
5. Open an immutable gauge capture, select its retained observation, and repeat.
   **Return to saved measurement** restores the exact receipt, native evidence,
   selected point and action without a capture-store GET. Capture custody time,
   original metric read time and fresh record read time remain separate.
6. A late record response after Return cannot replace the retained parent. Old,
   hidden or inert context actions cannot stage again. Returning renews only the
   current retained context action, not capture, source or display-save authority.

The fixture includes foreign services, instances, namespaces, conflicting current
versus legacy environment keys and metric-only attributes. Missing/empty/named
namespace cases and current-only/effective policies have separate actual oracles.
The 390px frame is generated by the real app. No screenshot or actor snapshot is
used as a substitute for exact source membership or immutable custody checks.
