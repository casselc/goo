# Reuse a few facts beside ungrouped records

The executable [main journey](404-summary-template.spec.js) uses ordinary OTel
logs and spans; [the actor](404-summary-template-actor.spec.js) independently
inspects and applies the saved span template. Executed results belong in
[VALIDATION](../VALIDATION.md). No positive source response is mocked.

1. Run a fixed ungrouped log question. Choose **Customize summary** beside the
   supplied population facts, then explicitly **Run population view**. The source
   question and its held parent remain unchanged.
2. Keep the captured-record count beside records. Under Save, enable **Reusable
   template**. The ordinary summary profile has no grouping slot; publishing
   saves configuration, not new evidence.
3. Repeat for spans with duration and recorded status. Choose recorded error
   fraction, count and mean duration in that order. Summary arithmetic/support
   comes from the existing source dataset; this template adds no evaluator.
4. Return to the exact held source result, then reopen the saved template.
   Reopening stages configuration and shows no source summary until Run.
5. Open a different compatible fixed population with a different predicate,
   environment policy, window and page limit. Load saved views and **Inspect
   template**. A pending expansion retired by a title edit cannot become current;
   inspect again to obtain a fresh checked preview.
6. **Apply template** imports summary fields/order and record presentation only.
   It preserves the complete destination question. Hidden, inert or retired Apply
   callbacks cannot act, and Apply performs no source read.
7. Explicit **Run population view** obtains destination evidence. Raw persisted
   rows independently establish population membership, duration/status facts and
   support. Save the destination template, reopen it source-free, then explicitly
   Run its unchanged question again.
8. Empty spans leave duration and error fraction unavailable; a real zero-duration
   span remains known zero. Neither is inferred healthy or complete.

Both source and destination are page-zero roots. Existing page limits remain
nondefault and exact; continuation pages do not gain template admission. Numeric
bindings, grouped/native/specialized summaries and arbitrary calculations remain
outside this initial template profile.

The actor opens the real configured destination at 390px, loads the real template,
inspects, applies and explicitly reads once. It checks exact destination scope,
field order, full supplied summary values and source basis, with no publication.
Setup configuration writes are recorded separately from actor operations.
