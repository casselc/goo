# Contextual action and return verification

Generated Hegel cases call the actual shared native readiness/focus helpers in a
small generated DOM tree. An independent boolean oracle supplies expected
invocation/completion availability and focus/disclosure effects across withdrawn,
disabled, inert, closed, hidden and stale-owner schedules. Current pending
completion may outlive its opener's own disabled state; invocation may not. The
first native legend exception is covered explicitly. `fetch` is denied.

This helper conformance test does not substitute for real owner/browser tests.
The source handlers separately hold their own leases and the browser journey
checks actual widget and record inspector controls. Return focus is explicitly
local, and opt-in native disclosure reveal must not revive a withdrawn owner.

The native Quint protocol separates source acquisitions, SQL reads and pure
comparison operations. It checks explicit service comparison, record acquisition,
inspector/trace transitions and current versus retired pending configuration
completion. The actual browser ledger must be continuous; each named local action
adds no source, SQL or comparison operation. The independent actor runs afterward.
Rejecting mutations add an illicit read to a local return or complete a retired
pending operation. This is a finite protocol, not exhaustive concurrency proof.

Root runs heavy checks serially from `verification/`, with current Go, Node and
the local Quint tool on PATH:

```
GOO_ACTIONS420_REPORT=/workspace/goo/artifacts/contextual-actions420/report.json \
  go test ./actions420 -count=1 -v
```

Quint absence fails. The actual-ledger test skips only for local helper-only
development without a report; milestone acceptance requires the passed real
journey and no skips.
