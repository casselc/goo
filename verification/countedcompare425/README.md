# Counted selection comparison (425)

A counted result supplies categorical choices, never the comparison operands.
The native Quint protocol separates local selection, search, staging, retained
Back and retired actions from explicit counted Load and comparison Run. Its
invariant conserves acquisitions, SQL reads and comparison requests. Negative
controls add reads to local actions, omit the comparison, stage an empty or
retired choice, and run before staging.

The actual completed browser report must include every continuous named fact.
Each observed effect is accounted for; missing facts, counter regression,
unrecorded effects and a mutated retained action fail. This validates the source
budget alongside the browser's exact queries, independent source oracle, native
controls, held rows and actual return focus; it does not infer them from clicks.

Hegel drives the production JavaScript planner. An independent finite-record
oracle verifies that selected and rest partition the unchanged parent predicate
for absent keys, empty strings, literal/Unicode values and namespace lookalikes.
Properties also verify immutable window/environment/grouping, deterministic
planning, ordinary-profile admission and whole predicate bounds. Each side is
still read independently: logical partition semantics do not promise equal read
clocks, stable ingestion or a conserved sum of observed totals.
