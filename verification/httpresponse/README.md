# Incoming HTTP response population properties

Run from the repository root with the configured toolchain:

```sh
(cd verification && go test ./httpresponse -run TestIncomingResponsePopulation -count=1 -v)
```

This isolated semantic package imports no private milestone helpers. Hegel varies
service/window input across environment policies, exact namespace states and four
profile choices. Whole dashboard wire round trips and compiled queries retain the
scope. The response query equals the existing Server-span activity query except
its grouping and the activity-only timeline projection; response context keeps
its page-zero limit of 100 and requests no timeline. Independent membership expectations cover current/legacy method
presence, literal response strings, missing/empty values, opposite span statuses,
and foreign service/namespace controls. Environment policy is checked as retained
query intent; actual persisted source membership belongs to the real journey.

These are generated planner/contract checks, not additional source observations or
an HTTP status classifier. No new query execution or state protocol is introduced.
