# Multi-value counted-facet verification

This isolated package tests the actual counted-value predicate helper and source
owner, rather than restating its builder. Thirty-two Hegel seeds generate log/
span scopes and local selection schedules. An independent truth evaluator checks
that alternatives are OR within one qualified field and AND with every retained
predicate, including an existing restriction on that field. Missing, empty and
literal lookalikes remain distinct; unrelated resource/attribute keys cannot
satisfy the choice. Large original counts never become draft population totals.

Negative controls cover duplicate/empty/malformed choices, numeric columns,
UTF-8/value/node/depth limits and input immutability on refusal. The real
FilterValues owner supplies a current lease to the renderer; changed scopes,
replaced reads, and an observed change-and-return cannot restore the old lease.
These are application state schedules, not a claim about arbitrary undetectable
external mutation or an exhaustive browser/concurrency proof.

The native Quint protocol separates local checkbox/search/clear/Stage gestures
from counted Load (one acquisition/two SQL reads) and explicit Apply (one
acquisition/one SQL read for the journey's paused first batch). It rejects empty
selection staging, early/extra reads and retired pending completion. The actual
main browser facts must be contiguous; the separate actor runs afterward.

Root runs heavy checks serially from `verification/` with the current Go, Node
and local Quint tools on PATH:

```
GOO_MULTIFACETS422_REPORT=/workspace/goo/artifacts/multi-value-facets422/report.json \
  go test ./multifacets422 -count=1 -v
```

Native Quint is mandatory. The observed-ledger test skips only when no report is
supplied for a local arithmetic-only check; milestone acceptance requires the
passed real-source report and no skips. Raw browser diagnostics remain ignored.
