# Service-version comparison verification

Root executes `go test ./serviceversions -count=1 -v` from the verification module.
The isolated Hegel test passes generated fixed parent configurations to the actual
JS helpers, with source IO denied, then checks exact discovery/side queries using
an independent Go oracle and the Go query/view validators. It covers typed named,
empty and unreported environments, missing/empty/named namespaces, exact operation
predicates, count and mean carriers, literal null/empty/Unicode/whitespace versions,
counts above JavaScript safe integer range, and rejecting altered DTO/scope/value
controls. It does not claim source observations or UI-owner coverage by itself.

`GOO_SERVICE_VERSIONS_REPORT=/absolute/path/to/report.json` enables mandatory
actual-journey replay alongside the synthetic Quint protocol/rejecting controls.
The model covers recorded per-gesture acquisition deltas: discovery2SQL, explicit
selected+baseline Run6SQL, and no-source local actions. It does not conflate
initial dashboard reads or a separate browser actor with that gesture protocol.
A final pending discovery records its started count query, then explicit retirement
adds no read and cannot admit a late response. The browser report independently retains those calls.
