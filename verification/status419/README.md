# Recorded Error version-context verification

This isolated Hegel test generates coherent recorded span-status partitions above
2^53, exact equal and unequal fractions, reversed signed changes, empty
populations and diagnostic withholding. The actual Go comparer produces the
supplied snapshots and changes. Independent `math/big.Rat` arithmetic checks the
values; the real JavaScript comparison validator admits each result and rejects
changed partitions, fraction support, aggregation descriptors and fabricated
changes. Inputs must remain unchanged; browser-held snapshots gain no coverage
attestation. Fetch is denied in the JavaScript bridge.

The native Quint protocol extends the prior version flow with supplied-data
comparisons: these may increment pure-comparison operations after an applied
pair, but cannot read a source or execute SQL. Discovery, explicit two-population
Run, local staging, held Back, failed discovery and departed pending discovery
retain separate source/API/SQL budgets. Rejecting controls prove local actions
cannot read and comparison Run cannot add extra SQL. This finite protocol is not
a concurrency or exhaustive browser proof.

Root executes heavy checks serially from `verification/`, with current Go,
Node and local Quint on PATH:

```
GOO_STATUS419_REPORT=/workspace/goo/artifacts/service-versions419/report.json \
  go test ./status419 -count=1 -v
```

Native Quint is mandatory and absence fails. The actual-ledger test skips only
for local arithmetic-only runs without a report; acceptance requires the passed
real-source 419 report and no skips. The observed run must include both recorded
Error count and fraction comparisons and held service return. Separate Bombadil
observations belong to the browser report rather than the main read ledger.
